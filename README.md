# Which Sweater Fits Which Kitten?

A see-and-tap matching game for families: put the right tiny sweater on each shy kitten.

## Play it

https://yoshiqueens.github.io/which-sweater-fits-which-kitten/

Works on a phone or a computer. One player, or pass the phone around.

## How to play

1. Tap Start.
2. Each kitten's thought bubble shows the pattern it wants. Its size shows which sweater will fit.
3. Tap a sweater in the basket, then tap the kitten it fits.
4. A first-try match scores 2 points; a match after a miss scores 1.
5. Three rounds, with more kittens each round.
